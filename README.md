## 核心功能

- **多账号无感托管**：支持无限车位小蚕账号，支持手动 Token、JWT 自动解析、PC 微信凭据嗅探与自签 CA 本地抓包。
- **全场景日常挂机 (15+ 项自动化任务)**：
  - 每日元宝任务、天天赚元宝签到、气泡元宝自动收取、元宝抽大奖、整点红包雨、元宝秒杀抢券。
  - SVIP 高额返利券秒杀、外卖大牌神券秒杀、影音周卡抢兑、免单券秒杀。
  - 支付宝夜间自动提现、JWT 临期与特权卡券到期主动通知预警。
- **毫秒级霸王餐抢单与预约**：
  - 支持按经纬度/城市/商圈检索与美团/饿了么多平台过滤。
  - 全城美团同店双返利雷达一键扫描（同时拥有实付满返与按比例返现方案）。
  - 高精度阿里云 NTP 毫秒授时校准，支持提前开抢冲刺（`early_ms`）与自动化提前预约。
- **订单全流程追踪**：自动记录抢单结果，支持外卖平台订单号回填与收益看板可视化分析。
- **多通道预警推送**：支持企业微信群机器人、钉钉机器人、飞书机器人、Server酱等多渠道提醒。

## 环境要求

在开始运行前，请确保系统已安装以下基础环境：

| 环境组件 | 最低版本要求 | 推荐版本 | 说明与下载链接 |
| :--- | :--- | :--- | :--- |
| **Git** | 2.20+ | 最新版本 | [Git 官方下载](https://git-scm.com/)，用于克隆和更新代码 |
| **Python** | 3.10+ | Python 3.11 或 3.12 | [Python 官方下载](https://www.python.org/)，安装时**务必勾选 "Add python.exe to PATH"** |
| **Node.js** | 18.0+ | Node.js 20 LTS | [Node.js 官方下载](https://nodejs.org/)，用于前端依赖管理与打包 |

> [!IMPORTANT]
> **Windows 用户特别注意**：
> 安装 Python 时，安装界面的第一个窗口底部有 `Add python.exe to PATH` 选项，必须勾选，否则命令行将无法直接识别 `python` 指令。

## 新手快速开始 (代码拉取与依赖安装)

### 第 1 步：拉取项目代码

打开终端（Windows 推荐使用 PowerShell 或 CMD），执行以下命令将项目代码克隆到本地：

```bash
git clone https://github.com/AkiSeele/xiaocan-assistant.git
cd xiaocan-assistant
```

---

### 第 2 步：选择运行方式

根据你的使用习惯选择以下任意一种方式启动：

#### 方式一：Windows 一键开箱即用 (普通用户推荐)

如果你是 Windows 用户且仅希望直接使用系统，根目录下已内置全自动引导脚本 `run.bat`：

1. **直接双击运行根目录下的 `run.bat`**；
2. 脚本将按顺序全自动执行以下动作：
   - 自动检测并创建 Python 独立虚拟环境 (`backend/venv`)；
   - 自动通过清华源镜像高速下载安装所有后端依赖包（FastAPI、HTTPX、APScheduler 等）；
   - 自动检测前端打包状态，若未打包则自动执行 `npm install` 与 `npm run build`；
   - 自动启动后端 Web 服务并在 2 秒后拉起默认浏览器访问 `http://127.0.0.1:8690`。
3. 以后每次使用，只需双击 `run.bat` 即可一键启动。

---

#### 方式二：Windows 双热加载开发模式 (开发者推荐)

如果你希望进行二次开发、修改前端界面或调整后端逻辑，双击根目录下的 `dev.bat`：

1. 自动启动后端服务（端口 `8690`，启用 Python 代码热重载）；
2. 自动启动前端 Vite 开发服务器（端口 `5173`，启用 React 19 HMR 毫秒级热替换）；
3. 浏览器自动打开 `http://127.0.0.1:5173`，修改任意页面或逻辑实时刷新生效。

---

#### 方式三：跨平台手动分步部署 (Linux / macOS / Windows)

如果处于 Linux 服务器或 macOS 环境，或者希望手动控制安装流程，请遵循以下分步指令：

##### 1. 后端依赖安装与启动

进入 `backend` 目录，配置 Python 虚拟环境并安装依赖：

```bash
# 进入后端目录
cd backend

# 创建虚拟环境
python3 -m venv venv

# 激活虚拟环境
# Linux / macOS:
source venv/bin/activate
# Windows (cmd):
venv\Scripts\activate.bat
# Windows (PowerShell):
.\venv\Scripts\Activate.ps1

# 使用国内镜像源高速安装依赖
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple

# 启动后端服务
python main.py
```
后端服务默认监听在 `http://0.0.0.0:8690`。

##### 2. 前端依赖安装与构建

另起一个终端窗口，进入 `frontend` 目录：

```bash
# 进入前端目录
cd frontend

# 安装前端依赖 (若网络较慢可使用淘宝 npm 镜像源)
npm install --registry=https://registry.npmmirror.com

# 运行模式 A：启动前端开发服务器 (带热重载，访问 http://localhost:5173)
npm run dev

# 运行模式 B：构建生产包 (构建到 frontend/dist，后端 8690 端口直接一体化托管访问)
npm run build
```

---

#### 方式四：Docker 容器化一键部署

系统原生支持 Docker 与 Docker Compose 部署：

```bash
# 构建并后台启动容器
docker-compose up -d --build

# 查看运行日志
docker-compose logs -f
```

启动完成后，直接在浏览器中访问宿主机 `http://127.0.0.1:8690` 即可。

## 使用指引与常见操作

### 1. 账号添加与凭据获取
系统支持多种小蚕账号接入方式（进入「账号管理」页面）：
1. **扫码或抓包链接自动解析**：在抓包工具或小程序中复制包含 `token=` 或完整接口响应的文本，直接粘贴到输入框，系统自动提取并解析 JWT；
2. **PC 微信本地自动嗅探**：启动内置嗅探器并安装本地临时根证书，打开微信电脑版中的小蚕小程序，系统自动捕获凭据并静默入库；
3. **手动录入**：填入手机号与 Token 即可完成绑定。

### 2. 自动化挂机任务配置
- 进入「任务配置」页面，勾选每日需要执行的任务（如天天赚元宝、元宝签到、领大红包、整点红包雨等）；
- 支持设置执行时间偏移量（抖动防风控），系统后台守护进程将在指定时刻自动执行。

### 3. 美团同店双返利与霸王餐抢单
- 进入「霸王餐抢单」页面，选择「美团同店双返利」标签页；
- 输入想要扫描的商圈或品牌关键词（如 `曼玲粥`），点击「扫描双返利店铺」；
- 系统将自动比对官方满减服务与按比例返现服务，聚合出**同一分店名下同时具备满减返与按比例返**的商家，并展示各档位精确抢单时间（如 `10:30 ~ 14:00`）；
- 支持点击「立即抢单」或设置「定时预约」。

### 4. 消息推送通知配置
- 进入「系统设置」页面，选择通知渠道（企业微信/钉钉/飞书/Server酱）；
- 填入对应 Webhook 地址并点击测试，抢单成功与关键资产变动将实时推送到手机。

## 常见问题与排查 (FAQ)

### Q1: 运行 `run.bat` 提示 "python 不是内部或外部命令"？
- **原因**：安装 Python 时未勾选将 Python 加入系统环境变量 PATH。
- **解决方法**：重新运行 Python 安装包，选择 `Modify`（修改），勾选 `Add Python to PATH`；或者手动在 Windows 环境变量中添加 Python 安装路径与 Scripts 路径。

### Q2: `pip install` 提示网络超时或下载极慢？
- **解决方法**：使用国内清华或阿里镜像源安装，命令如下：
  ```bash
  pip install -r backend/requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
  ```

### Q3: 前端 `npm install` 报错或依赖下载卡住？
- **解决方法**：配置 npm 国内镜像源并重试：
  ```bash
  npm config set registry https://registry.npmmirror.com
  npm install
  ```

### Q4: 启动后提示端口 8690 或 5173 被占用？
- **解决方法**：在 PowerShell 中执行以下命令查看并释放被占用的端口：
  ```powershell
  # 查找占用 8690 端口的进程 PID
  netstat -ano | findstr :8690
  # 终止该进程 (替换 1234 为实际 PID)
  taskkill /PID 1234 /F
  ```

### Q5: 本地数据与账号信息保存在哪里？如何备份？
- 系统数据保存在本地 SQLite 数据库中：`backend/data/xiaocan.db`。
- 系统已对该目录实施严格的 `.gitignore` 保护，绝不会被意外上传到 GitHub，备份时只需复制该 `.db` 文件即可。
